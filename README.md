# Timebrman

Projekt stworzony w Unity oraz przygotowany do wglądu dla koła naukowego AGH Code Industry. All Rights Reserved.

# Jak grać?
Gotowy zbuildowany plik z grą znajduje się w sekcji Releases.

# Sterowanie
Instrukcje co do sterowania postacią znajdują się w ustawieniach gry (tuż obok sekcji regulacji dźwięku)

# O projekcie
Cała gra została opracowana oraz przygotowana przeze mnie tj. wszystkie grafiki (poza tłem podczas gry przygotowanym przez mojego kolegę), dźwięki, muzyki oraz skrypty (poza systemem tabel i ewentualnymi drobnymi skryptami wygenerowanymi przez sztuczną inteligencję) zostały przygotowane przeze mnie. Projekt rozpocząłem latem 2025 i doczekał się on 3 update'ów w których dodawałem zarówno nową muzykę, grafikę oraz na przykład tryb multiplayer offline. Projekt został zakończony jesienią 2025
